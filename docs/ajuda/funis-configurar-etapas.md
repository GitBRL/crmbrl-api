# Configurar as etapas de um funil

1. Abra o funil e clique na ação de configurar etapas (modal "Configurar etapas").
2. Cada linha tem nome, prazo-alvo (em dias, usado para marcar negócio "parado") e probabilidade. Edite e salve a linha; cada linha salva ou descarta as próprias alterações.
3. Para reordenar, arraste a etapa ou use as setas de subir e descer.
4. Para criar, adicione uma etapa nova: ela entra antes da etapa de ganho.
5. Para remover, use remover na linha. Etapa com negócios não pode ser removida: o CRM explica o motivo; mova os negócios antes.

Regras: todo funil tem pelo menos uma etapa aberta, uma de ganho e uma de perda. As de ganho e perda ficam sempre no fim e o tipo delas não se edita. Os três funis-base (Marketing, Comercial e Customer Success) não podem ser excluídos.
