# Convidar e desligar usuários

**Quem pode:** só o Admin.

1. Abra **Administração → Usuários**.
2. Clique em **Convidar**, informe nome, e-mail, papel e líder.
3. Para desligar, abra o usuário e clique em **Desligar**; os negócios dele são redistribuídos.

Não existe exclusão definitiva de usuários: o desligamento preserva o histórico.
